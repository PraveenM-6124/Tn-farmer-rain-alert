# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Tamil Nadu Farmer Rain Alert & Marketplace seriously.
If you believe you have found a security vulnerability, please do NOT open a public GitHub issue.

Please report vulnerabilities privately by emailing security disclosures or contacting project maintainers.

### Security Guidelines
- **No PII in commits**: Never commit real farmer phone numbers, names, or exact farm coordinates.
- **No plaintext credentials**: API keys, database credentials, and OTP secrets must remain in `.env` (ignored by git).
- **Report response**: You will receive an acknowledgment within 48 hours and regular updates on fix progress.
